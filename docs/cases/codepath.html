Self analysis

CodePath 自分析案例

这个案例用于验证 CodePath 能否解释自身架构：从浏览器注入、侧边栏 UI、后台通讯、GitHub 源码读取， 到 MCP 工具注册和缓存管理。

项目：lgk-code/codepath-extension 目标：WXT / MCP / 缓存管理 方式：浏览器插件 + MCP

What to verify

测试目标

01

浏览器侧架构

确认分析能指出 content script 注入、Sidebar 渲染、background 请求处理和设置页配置的职责边界。

02

MCP 工具链路

确认分析能解释 `scripts/codepath-mcp.ts` 中的工具注册、输入输出结构和环境变量读取方式。

03

缓存管理

确认分析能说明 analyzer 中的持久化缓存、缓存列表、项目级删除和单项删除的关系。

Expected output

期望输出能力

项目概览 应引用 `entrypoints/`、`src/components/Sidebar.tsx`、`src/lib/analyzer.ts` 和 `scripts/codepath-mcp.ts`。
功能路径 输入“缓存管理”后，应说明缓存 key、storage、设置页列表和删除请求之间的调用链。
文件解释 解释 `scripts/codepath-mcp.ts` 时，应围绕 MCP 工具注册、结构化返回和 OpenClaw 使用方式。
