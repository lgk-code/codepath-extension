MCP server

npm run mcp

tools:
  analyze_github_project
  analyze_github_feature
  generate_openclaw_skill
  generate_project_blueprint
分析仓库 输出结构、技术栈、入口和阅读路线。

生成 Skill 把源码经验整理成 OpenClaw 可执行的任务草案。

Workflow

从 GitHub 地址到可执行方案

1. 提供仓库地址 用户或 OpenClaw 给出 GitHub URL 和目标功能。
2. CodePath 分析源码 读取仓库文件，提炼实现路径、关键模块和源码依据。
3. OpenClaw 执行任务 根据 Skill 或蓝图继续学习、重构、搭建或验证。
